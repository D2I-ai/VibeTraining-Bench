--- ## 概览 递归自改进（Recursive Self-Improvement, RSI）要求 agent 能够诊断系统瓶颈，并在训练与推理两侧协同推进改进。我们将 agent 同时优化训练数据、训练器与推理 harness 的能力称为 **跨组件协同设计（cross-component co-design）**。 **VibeTraining-Bench** 在终端操作、软件工程、多轮工具调用与数学推理等任务上评估这一能力。在每个任务中，研究 agent 从完全相同的初始 agent 系统出发，并在固定资源预算下工作。它们依据验证反馈迭代改进数据、训练器与推理 harness，随后选出最终 agent 系统并提交，在测试集上接受评测。 为防止 reward hacking，基准设置了三项防护措施：测试数据隔离、研究容器与评分容器分离，以及对研究 agent 的网络访问限制。 ![VibeTraining-Bench 总览](assets/images/main_figure.png) *研究 agent 在固定预算下从共享的初始资源出发，依据验证反馈迭代协同设计数据、训练器与推理 harness，并提交最终系统在隐藏测试集上接受评分。* ## 与我们先前综述论文的关系 VibeTraining-Bench 以我们先前综述 [*The Path to Recursive Self-Improving Agents: Foundation, Framework, and Future Directions*](https://www.preprints.org/manuscript/202608.0051)（Liu 等，2026）提出的统一研究框架为基础。该框架将基础模型、agent harness、agent 数据系统、agent 训练器与改进机制建模为一个耦合演化系统，以刻画自改进的范围与依赖关系。在此框架下，VibeTraining-Bench 对跨组件协同设计进行受控评测，考察研究 agent 能否在固定资源预算下协同改进训练数据、训练器与推理 harness。 ## 核心特点 - **跨组件，而非单组件**：agent 必须协同设计数据、训练与推理，而不是孤立地调优某一个模块。 - **受控对比**：所有研究 agent 从相同的初始 agent 系统出发，并在相同的资源预算下运行。 - **抗作弊评测**：评分与研究过程隔离，研究阶段受到严格的网络限制。 - **有增益，也有明显空间**：在 SWE-bench Verified 上，研究 agent GPT-6-Astra 将目标 agent 系统的性能从 32.9% 提升至 53.7%，接近人工开发的 instruct 模型的 55.4%；但如何通过迭代获得累积增益，仍是待解问题。 ## 即将开源 我们正在完成开源发布的最后准备工作。本仓库将包含： - 覆盖四个评测领域的 VibeTraining-Bench 任务集 - 评测 harness，包括研究/评分容器分离与网络限制机制 - 参考配置、基线系统与实验结果 敬请关注本仓库的后续更新。 ## 引用 如果本工作对你有帮助，欢迎引用我们的论文。 ```bibtex @misc{peng2026vibetrainingbench, title = {VibeTraining-Bench: Data-Trainer-Harness Co-Design for Iterative System Improvement}, author = {Ruotian Peng and Yuanyi Ren and Shuaiqi Liu and Xin Guo and Fang Zhu and Yangyi Huang and Yue Wu and Zheng Wang and Yandong Wen and Zhihang Fu}, year = {2026}, eprint = {2610.26342}, archivePrefix = {arXiv}, primaryClass = {cs.AI} } ``` ```bibtex @article{202608.0051, doi = {10.20944/preprints202608.0051.v1}, url = {https://www.preprints.org/manuscript/202608.0051}, year = {2026}, month = {August}, publisher = {Preprints}, author = {Shuaiqi Liu and Zhengkai Lin and Yuxiang Zhang and Yuanyi Ren and Yue Wu and Yongbin Li and Zheng Wang and Zhihang Fu and Jieping Ye}, title = {The Path to Recursive Self-Improving Agents: Foundation, Framework, and Future Directions}, journal = {Preprints} } ```
